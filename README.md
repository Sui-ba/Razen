# RyzenHub — Сборка и ремонт ПК

Сайт сервиса сборки, ремонта и обслуживания компьютеров в Томске.

**Живой сайт:** https://sui-ba.github.io/compville-site/

## Что внутри

- Тёмный премиум-дизайн (цвета логотипа: cyan + orange)
- Раздел **Услуги** с фото (сборка, ремонт, чистка, апгрейд, ПО, доставка)
- Многошаговая **анкета** заявок
- Сохранение заявок в `localStorage`
- Отправка заявок в **Discord** (webhook) и/или **Telegram** (бот)
- **Админ-панель** `/admin.html` (пароль по умолчанию: `ryzen2026`)
- Пользовательское соглашение и Политика конфиденциальности
- Ссылка на Авито-профиль
- Адаптив под мобильные

## Настройка уведомлений

Откройте `app.js` и заполните:

```js
const DISCORD_WEBHOOK = "https://discord.com/api/webhooks/...";
// или
const TELEGRAM_BOT_TOKEN = "123456:ABC...";
const TELEGRAM_CHAT_ID = "123456789";
```

Discord webhook — самый простой вариант (создаётся в настройках сервера → Интеграции).

## Админка

- URL: `/admin.html`
- Пароль по умолчанию: `ryzen2026` (меняется в `app.js` → `ADMIN_PASS`)
- Заявки видны только в том браузере, где их оставляли (localStorage). Для реальной работы обязательно настройте Discord/Telegram.
