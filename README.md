## Как открыть сайт

1. Репозиторий: https://github.com/Sui-ba/Razen  
2. GitHub Pages уже включён (ветка `main`, корень).  
3. Адрес сайта: **https://sui-ba.github.io/Razen/**  

Если страница не открывается — зайди в **Settings → Pages** репозитория и убедись, что Source = `Deploy from a branch` → Branch: `main` → `/ (root)` → Save. Через 1–2 минуты сайт появится.

## Настройка уведомлений о заявках

В файле `app.js` в начале:

```js
const DISCORD_WEBHOOK = "https://discord.com/api/webhooks/...";
// или
const TELEGRAM_BOT_TOKEN = "токен_от_BotFather";
const TELEGRAM_CHAT_ID = "твой_chat_id";
```

**Discord** — самый простой способ: сервер → Настройки → Интеграции → Webhooks → Новый webhook → скопировать URL.
