## Настройка

В начале файла `app.js`:

```js
const DISCORD_WEBHOOK = "https://discord.com/api/webhooks/...";
const TELEGRAM_BOT_TOKEN = "";
const TELEGRAM_CHAT_ID = "";
const ADMIN_PASS = "ВАШ_НАДЁЖНЫЙ_ПАРОЛЬ";  // обязательно смените!
```

**Важно:** пароль админки хранится только в `app.js`. Нигде в интерфейсе и README он не показывается.

## Личный кабинет

- После заявки создаётся пользователь (если новый).
- Логин: телефон или email.
- Временный пароль показывается один раз на экране успеха.
- При первом входе — обязательная смена пароля.
- В кабинете видны все заявки пользователя и их статусы (этапы работы).

Кабинет **не обязателен**: можно просто оставлять заявки без входа.

---

## Админ-панель

- Адрес: `/admin.html`
- Пароль задаёте сами в `ADMIN_PASS`.
- Вкладки/фильтры по статусам: Новая → На рассмотрении → В работе → Ждём запчасти → Готово → Завершена / Отменена.
- Можно менять статус и писать комментарий к смене.
- Статистика по количеству заявок.

Данные хранятся в `localStorage` этого браузера. Для реальной работы настройте Discord/Telegram-уведомления. Для полноценной БД (SQL) и синхронизации между устройствами рекомендуется подключить backend (например Supabase / Firebase / свой Node + SQLite).

## Защита

- Пароли пользователей хешируются (SHA-256) перед сохранением.
- Админ-вход с ограничением попыток.
- Сессия кабинета ограничена по времени.
- Ссылки на админку убраны с публичных страниц.
- Пароль админа не светится в README и на сайте.

Клиентская защита имеет ограничения (это статический сайт). Для серьёзной защиты нужен сервер.
